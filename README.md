# 潮切

中文名：**潮切** · 前缀 `tide` · 端口 **7900**

## 骨架（新骨，不是闸对/对拍/缝包换皮）

**观测点装载 → 事件时入窗缓冲 → 关窗物化切片 → 迟到/乱序旁路 → 窗账与缓冲互证**

| 对比 | 闸对 | 对拍 | **本仓** |
| --- | --- | --- | --- |
| 拓扑 | 单流入→开腿→成对 | 双轨装载→键对齐 | **单流入→入窗缓冲→关窗物化** |
| 在途 | 开腿账 | 悬账单（对齐后） | **入窗缓冲（未关窗）** |
| 产物 | 行程账 | 对齐差+结论 | **窗切片账** |
| 旁路 | 旁路匣 | 悬账/缺边 | **迟到匣（事件时出窗）** |

皮：物流网点运单轨迹上报。去皮：**事件时关窗管道 + 缓冲 + 迟到旁路 + 窗贯验**。  
禁止做成运单 CRUD、配送看板、工单系统。禁止抄闸对开腿/对拍左右轨命名。

## 已实现：关窗半截回滚（形态一·窗封印指纹回退）

关窗是一趟事务：`BEGIN IMMEDIATE` 取互斥 → 清场上一趟残片 → 按运单物化
（切片账 + 切片事件 + 缓冲改已物化）→ 收口回执 / 封印指纹同事务提交。
任一环节失败：`ROLLBACK` + 兜底清本趟痕迹，封印账写失败指纹（有效=0），
本趟已写片与已物化缓冲**整趟退回**，贯验改读**空片集**。两位同时关窗只会成片
一次；再次关窗先清场，不残留半窗现行。

切片账、入窗缓冲、窗贯验、关窗收口共用 `app.services.收口` 的同一套「现行片集」
谓词，四处读同一套集合。

只读收口接口：`GET /api/关窗/收口`（趟号 · 现行片数 · 归档键 · 形态标记 · valid
· 失败指纹 · 封印账）、`GET /api/关窗/快照`（同事务取收口与片集）、
`GET /api/关窗/残片`。

夹具：`关窗中断样例`（窗规补丁 `关窗故障=物化半截`，人为中断）、
`成功成片对照`（全量现行）、`空缓冲对照`（空窗收口）。
