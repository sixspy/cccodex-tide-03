# 潮位报文归集台

港务水文组收到各潮位站的定长报文。归集员把一批报文贴进来，系统按站码和时刻解析、去重，
能落库的写入归集表；同一站同一时刻再来的行，按**当日去重设置**裁决为整行拒绝或厘米覆盖，
列数不对、站码坏了、观测时刻空着的行单独列出。所有裁决都在服务端完成。

## 去重规则

- 同一站码同一观测时刻再次出现时，不再一律拒绝，处理方式二选一：
  - **拒绝重复（reject）**：整行留在未接纳，已落库的厘米不动。
  - **覆盖厘米（overwrite）**：新厘米覆盖旧值，覆盖前的原值写进覆盖留痕，时刻详情可对照。
- 当日处理方式随**第一批报文**声明并锁定，当天不能再换；请求里的处理方式与当日设置
  对不上时，服务端写一条「时刻处理不符」的未接纳记录并停下，本批后续行不再处理（409）。
- 两批报文同时撞上同一站同一时刻：加咨询锁后只许一批写入，另一批记「时刻争用」。
- 观测时刻空着的行不参与去重，直接进未接纳。
- 覆盖进行中（有批次事务在途）不许改去重设置，接口返回 409。

## 页面

- **去重设置卡片**：当日策略、锁定状态，归集员可在锁定前选择处理方式。
- **重复列表**：站码、观测时刻、覆盖次数、处理名，分「覆盖区」和「拒绝区」两栏；
  争用、处理不符归在拒绝区并带单独标签。
- **时刻详情**：当前厘米与每次覆盖的覆盖前/覆盖后厘米对照，附该时刻全部未接纳记录。
- **批次对照卡片**：已落库表、覆盖对照（旧厘米 → 新厘米）、未接纳（带拒绝/争用/处理不符标签）。

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/dedup-setting` | 当日去重设置与可选项 |
| PUT | `/api/dedup-setting` | 改当日设置（归集员；锁定或在途时 409） |
| GET | `/api/duplicates` | 重复列表，分拒绝/覆盖两区 |
| GET | `/api/duplicates/{station}/{yyyymmddHHMM}` | 时刻详情，新旧厘米对照 |
| POST | `/api/batches` | 归集一批，body 带 `duplicate_policy` |
| GET | `/api/batches`、`/api/batches/{id}` | 批次列表与详情（含覆盖留痕） |

## 技术栈

| 层 | 选型 |
|----|------|
| 接口 | Python FastAPI |
| 页面 | Vue 3，无组件库 |
| 数据库 | PostgreSQL 16（咨询锁做站时刻与设置门闩） |

## 报文格式

每行四段，用竖线分开：站码、十二位时间、潮位厘米、质量旗。质量旗 A 是实测，
M 是插补，B 是可疑。时间段留空的行进未接纳，不参与去重。
